## Funktionsblöcke
- **Rampengenerator** – NE555P Timer
- **PWM-Komparator** – LM2903
- **Gate-Treiber** – BC547 / BC557
- **PID-Regler** – LM358 Op-Amp
- **Leistungsstufe** – MOSFET + MBR745 Schottky-Diode
- **Ausgangsfilter** – 50µH Induktivität + 470µF
